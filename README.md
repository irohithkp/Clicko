## Download Clicko

**Latest version:** v0.3.0

Download `Clicko-Setup-v0.3.0.exe` from the [GitHub Releases](YOUR_GITHUB_RELEASES_URL) page.

### Install
1. Download and run the installer.
2. Follow the setup wizard.
3. Choose whether to create a desktop shortcut.
4. Launch Clicko from the Start Menu or desktop.

The installer may request administrator permission.

### Controls
- **Move Clicko:** Click and hold the visible cat or keyboard artwork, drag it, and release.
- **Quit:** Press `Ctrl + Alt + Q`.

Clicko is an early-development project for Windows x64.
